##Cattle Lameness Detection

##Project Overview

This repository contains the project files developed during my internship, focused on building an AI system to automatically classify cattle locomotion as lame or normal from video data to assist in livestock health monitoring.
##Technologies used
Python, YOLOv8, OpenCV, Pathlib

##Workflow and Execution
The project was executed within Google Colab. The core scripts, such as train_ml.py, along with necessary configuration files and initialization scripts, are committed to this repository.

##Datasets and Google Drive Integration
Large video datasets and model weights are stored and managed directly in Google Drive to work seamlessly within the Google Colab environment.
To run the project, ensure you download all required datasets and files from your Google Drive and place them in the correct directory paths as specified by the configuration files.

##Acknowledgments
This project utilizes datasets and baseline code originally provided by the creators of the MmCows dataset. Proper credit is given to the original authors for providing the foundation for this work.

##Setup and Usage
1. Clone this repository or open the scripts directly in Google Colab.
2. Download all required datasets from your Google Drive and mount your Drive within Colab.
3. Ensure all dependencies listed in requirements.txt are installed.
4. Run the scripts using the configuration files provided.
